# 月曆小工具（CalendarWidget）

固定在 Windows 桌面上的月曆：一眼看到本月、今天有什麼行程與待辦，到時間跳出提醒。很省資源（閒置時 CPU 幾乎是 0、記憶體約十幾 MB 到數十 MB），不需要安裝，也沒有伺服器，你的資料只存在你自己的電腦。

> 目前是 **0.9 測試版**：功能大致齊全，但有幾項還沒在真實環境完整驗證，詳見 [CHANGELOG.md](CHANGELOG.md) 的「已知限制」。

## 功能

- **月曆**：週日或週一開頭，日期下面有圓點表示當天有東西（顏色依來源）；平日的放假日與補假標紅字，補班日不標。
- **行程來源**：
  - Google 日曆與 Google 待辦（讀取、新增、編輯、刪除行程）
  - ICS 網址（Outlook、Apple、各種公開日曆都能用）
  - 本機行程與本機待辦（不經過網路）
- **提醒**：行程提醒（依各行程自己的設定，或統一提前幾分鐘）、節日前一天提醒；提醒框可以按「知道了」或「5 分鐘後再提醒」。
- **颱風假通知**（預設關閉）：你關注的縣市或鄉鎮區停班停課時跳出提醒，日期標紅字。
- **依條件產生台灣節日的 ICS 檔**：可存成檔案，或直接加進月曆。
- 外觀可調：整體大小、月曆寬度、下方清單與圓點的大小、透明度、位置（可鎖定）。

## 下載與安裝

1. 到 [Releases](https://github.com/meme755144/calendarwidget/releases) 下載最新版的 `CalendarWidget-x.y.z.zip`，解壓縮到任何資料夾（不需要安裝程式）。
2. 執行 `CalendarWidget.exe`，桌面會出現月曆，系統匣會出現小圖示。

**需求：** Windows 10 / 11，.NET Framework 4.8（Windows 10 1903 之後內建，更舊的系統請先安裝）。

**第一次執行可能出現 SmartScreen 警告。** 這個程式沒有數位簽章（簽章要花錢、還要驗證身分，目前先不做），Windows 會顯示「Windows 已保護您的電腦」。點「其他資訊」→「仍要執行」即可。想確認檔案沒有被更動，可以比對 SHA256（Releases 頁面每個版本都有寫）：

```
Get-FileHash .\CalendarWidget-0.9.1.zip -Algorithm SHA256
```

**更新：** 系統匣圖示按右鍵 →「檢查更新」（或設定 →「關於」）。只有你按了才會連線到 GitHub 查詢；有新版會提示，由你決定要不要打開下載頁面。程式不會自己檢查，也不會自己下載或安裝。

**移除：** 關閉程式，刪除資料夾。如果開過「開機自動啟動」，先到設定取消勾選。程式存放的資料在 `%APPDATA%\CalendarWidget\` 與 `%LOCALAPPDATA%\CalendarWidget\`，要清乾淨就一併刪除。

## 怎麼用

### 月曆

| 想做的事 | 操作 |
| --- | --- |
| 換月份 | 滑鼠在月曆上時用滾輪（往上前一個月、往下後一個月），或點標題兩側的 ‹ › |
| 直接跳到某年、某月 | 點標題的「年」選年份、點「月」選月份，選完直接回到日期畫面 |
| 看某天有什麼 | 點那一天，下方列出當天的行程與待辦；滑鼠停在日期上也會顯示提示 |
| 收合下方清單 | 點下方清單上的日期那一整行 |
| 回到今天 | 點「今天」，或系統匣右鍵 →「回到今天」 |
| 月曆被蓋住了（例如按了 Win+D 顯示桌面） | **雙按系統匣圖示**，或系統匣右鍵 →「顯示月曆」，月曆會出現在其他視窗的最前面 |
| 新增行程 | 在日期上按右鍵 →「新增行程」，可以選要加到 Google 日曆還是本機 |
| 修改或刪除行程 | 下方清單裡 Google 或本機行程旁的 ✎ 與 ✕（只限你有編輯權限的日曆；重複行程只動那一次；ICS 來源不能改） |
| 新增待辦 | 下方的輸入框輸入後 Enter；點方框勾選完成，✕ 刪除（會先問一次） |
| 移動位置 | 用滑鼠拖曳（到「設定 → 一般」勾選「鎖定位置」後就不會被拖動） |

### 設定

系統匣圖示按右鍵 →「設定」。分頁如下：

- **一般**：外觀（整體大小、月曆寬度、透明度、週起始日）、資料（載入範圍：外部日曆往前、往後各載入幾個月；是否標示放假日）、提醒（節日提醒與行程提醒的方式、間隔與時段）、系統（開機自動啟動）。
- **日曆**：所有來源的日曆集中在這裡，勾選要顯示哪些、改顏色、類型（行程或節日），用握把拖曳調整顯示順序。
- **ICS 來源**：新增、移除 ICS 網址，設定多久更新一次。網址會用 Windows 的資料保護加密存放。
- **Google 帳號**：只管登入與中斷連接。
- **ICS 產生**：依條件產生台灣的節日 ICS。
- **颱風假**：開關、關注的縣市與鄉鎮區。
- **關於**：版本、檢查更新、版本紀錄、連結、授權與免責聲明。

### 連接 Google 帳號

設定 → Google 帳號 →「連接 Google 帳號」，瀏覽器會打開 Google 的授權頁，在那裡登入並同意。登入在你的瀏覽器完成，程式看不到你的密碼。

- 平常只要求**讀取**日曆與待辦的權限。第一次在月曆上新增、修改或刪除 Google 行程時，才會另外請你授權「寫入行程」，而且只會在你按下按鈕時才更動你指定的那一筆。
- 目前這個應用程式還沒通過 Google 的驗證，登入時可能看到「這個應用程式未經 Google 驗證」的警告。點「進階」→ 繼續即可；這是因為驗證還在申請中，不是程式有問題。
- 隨時可以到設定按「中斷連接」：會通知 Google 撤銷授權，並刪除本機的憑證與行程快取。也可以到 [Google 帳戶的權限頁面](https://myaccount.google.com/permissions) 撤銷。

### 提醒

- **行程提醒**預設依各行程自己的設定（Google 行程的提醒、ICS 檔裡的提醒）；也可以改成所有有時間的行程都固定提前幾分鐘（最多 28 天），或完全不提醒。同一個行程同時到時間的多個提醒只列一行。整天行程的提醒依它自己的設定，自訂提前幾分鐘的模式不會提醒整天行程。
- **節日提醒**：節日前一天提醒，間隔與時段可以設定。
- 提醒框出現在右下角：按「知道了」之後不會再提醒那一筆；按「5 分鐘後再提醒」會稍後再跳。

### 颱風假通知

設定 → 颱風假 打開之後，程式會定時讀取停班停課資料。

- **預設關閉。** 關閉時不連網、不佔資源；打開後開機（或睡眠醒來）立刻讀一次，之後每 10 分鐘讀一次。
- 縣市用按鈕點選：選了的縣市整個縣市停班或停課時通知。每個已選的縣市底下可以另外勾選要通知的鄉鎮區；沒勾任何區就不通知鄉鎮區。單一學校的停課不通知。
- 資料來源是另一個獨立的專案 [taiwan-typhoon-days](https://github.com/meme755144/taiwan-typhoon-days)：它定時整理人事行政總處「天然災害停止上班及上課情形」網頁，輸出 JSON。程式只讀那份 JSON，不會自己去爬政府網站。
- 資料不是官方的，可能延遲或遺漏，實際停班停課**以官方公告為準**。看不懂的公告格式、資料來源被擋或太久沒更新，都不會默默略過：看不懂的公告會跳出「請自行查看」，資料超過 8 小時沒更新會在設定畫面提示。

### 疑難排解

- **桌面上看不到月曆：** 月曆平常固定在所有視窗的最底層，按了 Win+D（顯示桌面）後會被桌面蓋住。雙按系統匣圖示就能叫出來。
- **系統匣看不到圖示：** 先看隱藏的圖示（工作列右下角的 ^ 箭頭）。檔案總管重新啟動後圖示會自動回來。
- **Google 行程沒有出現：** 設定 → Google 帳號 看有沒有顯示「登入已失效」或更新失敗的訊息；到「日曆」分頁確認日曆有勾選；再按「立即更新」。登入已失效時按「重新連接」。
- **新增行程時說「沒有權限」：** 那個日曆你只有讀取權限（例如別人分享給你的日曆、節日日曆），請選別的日曆，或選「本機」。
- **ICS 來源更新失敗：** 設定 → ICS 來源 會顯示失敗原因（例如 HTTP 404、連線逾時）。網址必須是 http、https、webcal 或本機檔案，檔案不能超過 10 MB。
- **程式出錯：** 程式會把錯誤記錄在 `%LOCALAPPDATA%\CalendarWidget\error.log`，並繼續執行。回報問題時可以附上這個檔案（內容有程式所在的資料夾路徑，請自己看過再貼）。
